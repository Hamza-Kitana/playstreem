# Al-Daboor

منصة ألعاب تفاعلية للبث المباشر على Kick. اربط قناتك ويقرأ الموقع تعليقات الشات ليشغّل الأسئلة، كرسي الاعتراف، التصويت، وتقييم الأشخاص.

## التشغيل محلياً

```sh
npm i
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادةً `http://localhost:3000`).

## الصفحات

| المسار | المحتوى |
| --- | --- |
| `/` | الصفحة الرئيسية |
| `/about` | من نحن |
| `/contact` | تواصل معنا |
| `/streamers` | الستريمر الموثقين |
| `/connect` | ربط قناة Kick أو الوضع التجريبي |
| `/quiz` | أسئلة وأجوبة |
| `/seat` | كرسي الاعتراف |
| `/vote` | التصويت |
| `/rate` | تقييم شخص |
